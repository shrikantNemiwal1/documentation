The Google Sheets toolset lets an agent create a spreadsheet, read cells, write cells, add rows and clear ranges, acting as the Google account that connected the toolset.

## What agents can do

| Tool | What it does |
|------|-------------|
| `create_spreadsheet` | Create a new spreadsheet, optionally with named sheets (tabs) |
| `get_spreadsheet` | List a spreadsheet's sheets and their sizes, without the cell values |
| `get_values` | Read the cells in one range |
| `batch_get_values` | Read several ranges in one call |
| `update_values` | Overwrite the cells in a range |
| `append_values` | Add rows after the last row of data, without overwriting anything |
| `clear_values` | Erase the values in a range, keeping its formatting |

Tools that change a spreadsheet (`create_spreadsheet`, `update_values`, `append_values`, `clear_values`) act right away in the connected account.

**Ranges** use A1 notation, for example `Sheet1!A1:C10`, or just a sheet name such as `Sheet1` for the whole sheet. **Values are read as if typed** by default (`USER_ENTERED`), so `=SUM(A1:A3)` becomes a formula and `2026-10-15` a date. An agent can ask for `RAW` to store values exactly as given.

Reads return up to 20,000 cells; a larger range is cut and marked `truncated`, so ask for a smaller range.

A tool finds a spreadsheet by its id: the part of the link after `/spreadsheets/d/`. To work with a spreadsheet you only know by name, also add the [Drive toolset](/toolsets/google-workspace/drive) so the agent can search for it.

## Permissions it asks for

| Scope | Why |
|-------|-----|
| `https://www.googleapis.com/auth/spreadsheets` | Read and edit the spreadsheets the account can open, and create new ones |

Sheets has its own sign-in, separate from Drive, Gmail and Calendar. Connecting it never asks those toolsets to sign in again.

## Set up

<Steps>
  <Step title="Enable the Google Sheets API">
    In [Google Cloud Console](https://console.cloud.google.com/), open your project, go to **APIs & Services > Library**, search for **Google Sheets API** and click **Enable**.
  </Step>
  <Step title="Add the scope to the consent screen">
    In **APIs & Services > OAuth consent screen > Scopes**, add `https://www.googleapis.com/auth/spreadsheets`.
  </Step>
  <Step title="Copy the redirect URI from PipesHub">
    In PipesHub, go to **Settings > Toolsets**, find **Sheets**, click **Configure** and copy the **Redirect URI**.
  </Step>
  <Step title="Create an OAuth client">
    In **APIs & Services > Credentials**, click **Create Credentials > OAuth client ID**, choose **Web application**, paste the redirect URI under **Authorized redirect URIs**, and click **Create**. Copy the **Client ID** and **Client Secret**.
  </Step>
  <Step title="Connect in PipesHub">
    Back in the Sheets dialog, enter the Client ID and Client Secret and click **Authenticate**. Sign in to Google, allow access, and the toolset shows **Authenticated**.
  </Step>
</Steps>

You can use the same OAuth client as your other Google toolsets: add this toolset's redirect URI to it and enable the Sheets API in the same project.

## Errors you may see

| Message | What to do |
|---------|-----------|
| "…has not given this app permission to do that…" | Reconnect the Sheets toolset in **Settings > Toolsets** and allow Google Sheets access |
| "…could not find that spreadsheet or range…" | Check the spreadsheet id and the sheet name in the range |
| "…too many requests right now…" | Wait the time the message gives, then try again |
| "…the Google sign-in has expired or was revoked…" | Reconnect the Sheets toolset |

## FAQ

<AccordionGroup>
<Accordion title="How is this different from the Google Sheets connector?">
The [connector](/connectors/google-workspace/sheets/sheets) indexes spreadsheets so they appear in search and chat answers. The toolset lets an agent act on spreadsheets: create them, write cells and add rows. Use both if agents should find spreadsheets and also update them.
</Accordion>
<Accordion title="Can I undo a clear?">
Not from PipesHub. Use **File > Version history** in Google Sheets to restore an earlier version.
</Accordion>
</AccordionGroup>
